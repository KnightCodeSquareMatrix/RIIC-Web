# 寻访分析口径

核查日期：2026-10-10。

## 小黑盒参考的核查结果

用户提供的 [小黑盒分享入口](https://www.xiaoheihe.cn/tools/common_share?appid=131&share_bg_color=0160FF&is_v2=true) 返回公共分享壳，浏览器脚本加载分享信息并打开 App 小程序。公共脚本未包含明日方舟欧非阈值、当期评分或生涯评分算法。脚本引用的公开分享详情接口在未登录请求下返回 `status: failed`，未尝试绕过签名或登录限制。

因此不能把自行推定的阈值称为小黑盒原规则。截图中的个别“超欧”“超非”样例不足以确定完整阈值和评分公式。用户已明确选择先实现本站透明规则，并标注非小黑盒算法。

## 本站评分

- 顶部生涯和当期评分均为 `clamp(100 − 六星平均抽数, 0, 100)`，均展示称号、不显示数字。生涯称号位于生涯评分标题下，当期称号位于玩家名字旁。当期没有已保存记录时显示绿色“屯屯鼠”；加载中或读取失败时不据此显示屯屯鼠，当期已有抽数但未出六星时不显示评分称号。生涯无可评分记录时显示“—”。卡池内不展示评分。
- 两处称号统一配色：0–不足 40 分红色，40–不足 60 分黄色，60–100 分绿色。生涯统计全部已保存记录，当期仅统计正在开放的卡池。
- 经用户确认，称号按每 10 分一档采用同风格命名，非小黑盒等级或原算法。由低到高为：究极非酋、资深非酋、非酋本酋、时运不济、平平无奇、小有欧气、欧气渐盛、鸿运当头、天选欧皇、至尊欧皇。区间左闭右开，最高档包含 100 分，按未四舍五入的分数判定。
- UP 平均和歪卡不参与评分，避免不同卡池 UP 概率、未知自选名单造成隐含加权。
- 进度条只展示抽数，不展示评分或欧非等级标签。
- 评分不是概率分位、玩家排名或下次抽卡预测。评分覆盖范围与保存记录相同。

## 当前统计

- 所有指标只覆盖当前森空岛角色的已保存记录，不代表未上传的完整游戏生涯。
- 六星出卡数按次数计数，重复获得同一干员仍计数。
- 六星平均 = 已结束的六星区间抽数合计 / 六星出卡数。剔除各保底组末尾尚未出六星的抽数；标准、中坚按各自共享保底结算，限定、联动与其他池各自结算；零六星时不输出平均。最早区间可能只有部分保存记录。
- UP 六星以对应卡池明确的六星 UP 名单判定；名单缺失、自选目标未知时不推断“歪”。限定池的往期加权干员不作为当期 UP。
- 歪卡数 = 可判定名单中不属于当期 UP 的六星次数；歪卡率 = 歪卡数 / (UP 六星数 + 歪卡数)。无法判定的六星另列。
- UP 平均 = 各卡池从首条保存记录至最后一次 UP 六星的抽数合计 / UP 六星次数。每个卡池最后一次 UP 之后的抽数（包括歪掉的六星）不参与平均；零 UP 的卡池不计入分子，全部零 UP 时显示“—”。不同卡池目标不同，不将上一卡池尚未出 UP 的抽数结转给下一卡池。
- 卡池分类来自国服解包的 `gachaRuleType`。联动并入限定统计，但各池仍独立结算、不共享保底；跨年欢庆、定向甄选、归航和未知规则列为其他，避免按 ID 前缀错误混入共享保底。
- 标准寻访（NORMAL/SINGLE/DOUBLE）之间累计垫抽；中坚寻访（CLASSIC/CLASSIC_DOUBLE/FESCLASSIC）之间单独累计，两者不互通。
- 单池垫抽为该池最后六星之后的连续抽数；同一十连按时间戳和 `pos` 排序。垫抽仅在顶部按当前保底组展示，下方卡池不展示本池或池末垫抽。
- 未保存到上一位六星时显示“≥”作为下限。记录中间缺失无法据现有数据自动检测或恢复。
- 未出六星的卡池保留统计卡片，但不生成“待出六星”进度条。

## 截图核对与展示

用户截图中，中坚共 75 抽、2 个六星、已垫 21 抽，六星平均 27.0，符合 `(75 − 21) / 2`。标准共 1014 抽、27 个六星、13 歪、已垫 2 抽，若最后六星为 UP，`(1014 − 2) / (27 − 13) = 72.3`，与截图一致。这是对展示数值的核对，不是取得了小黑盒完整算法。限定平均 43.1 所需的分池区间无法从截图单独还原。

- 主统计依次展示限定（含联动）、标准、中坚；限定与标准显示出卡数/歪、UP 平均，中坚显示出卡数、六星平均。其他池有记录时作为第四张卡片同排展示。
- 出卡、歪卡、平均抽数集中在顶部展示，下方卡池卡片不重复展示这些统计。
- 垫抽另设一排，限定仅显示当前仍开放的池，无进行中池时不将历史池尾数带入。
- 基础六星概率：已垫 0–49 抽为 2%，50 抽为 4%，随后每次增加 2%，98 次未出后下一抽为 100%。未知历史用下限表示，超过规则有效范围的记录不计算概率。此概率不模拟定向选调、特殊保证。
- 当前卡池评分合并仍开放卡池的已保存记录，不冒充未确认起止范围的游戏版本评分。
- 完整十连的多金次数、同池连续 UP 次数显示为绿色成就。每个限定卡池的已保存抽数独立计算 `floor(抽数 / 300)` 后汇总为红色“抽满一井 / 抽满 N 井”；不足 300 的尾数不跨池凑整，标准、中坚、联动和特殊池不计入。该标签是抽数成就，不表示实际兑换次数或干员潜能。
