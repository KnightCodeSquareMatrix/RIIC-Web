# Admin 界面迁移方案

基线：main c1c4bdb。参考 [satnaing/shadcn-admin](https://github.com/satnaing/shadcn-admin) 的导航与数据表格交互，在现有 Next.js 应用中实现。以上迁移范围已实现，视觉验收待用户完成。

## 本地预览

在当前工作树运行 `npm run dev:admin-preview`，访问 http://127.0.0.1:5174/admin-preview 。端口被占用时可运行 `npm run dev:admin-preview -- 5175`。

- 六个页面复用正式后台客户端组件，演示数据与操作只保存在浏览器内存中；刷新、重置、切换角色或语言会恢复数据。
- 顶部可切换管理员/审阅人。用户角色确认、封禁、会话操作、反馈处理、技能注释以及日志草稿使用演示数据。
- 复现任务的导入/执行、日志发布等外部操作未模拟，页面会提示限制。预览不代表真实数据库集成验收。
- 正式后台仍在 `/admin`，需要原有账号权限；启动预览不绕过登录。生产环境始终关闭 `/admin-preview`，即使设置预览开关也返回 404。

## 验证命令

- `npm run check:i18n`：翻译键与语言配置。
- `npm run test:admin-preview`：环境入口开关、请求隔离、演示权限和数据重置。
- `npm exec -- tsc --noEmit --incremental false`：类型检查；首次运行前由 Next.js 生成路由类型。
- PowerShell：`$env:ADMIN_UI_PREVIEW='1'; npm exec -- playwright test --config=playwright.admin-preview.config.ts`：六页导航、用户筛选/分页/角色确认、权限菜单、页面搜索、窄屏与英文。
- `npm run build`：生产构建。与预览并行时设置 `RIIC_NEXT_DIST_DIR=.next-admin-build`，使用独立产物目录。

未配置隔离测试数据库，真实账号的完整权限与写入回归仍需在测试环境验收。

## 实施范围
1. 六个页面统一进入后台侧栏框架，按运行与审阅、内容与账户分组；桌面可折叠，手机使用抽屉。保留页面 URL、服务端权限和审核员可见范围。
2. 概览以求解指标优先，服务指纹和诊断置于其后；统一所有页面的标题、宽度、间距和操作区。
3. 用户管理改为表格，提供当前结果集的角色/状态筛选、排序和分页；服务器姓名/邮箱搜索不变。保留角色确认、封禁和会话管理。
4. 反馈、复现、技能和更新日志保留业务交互，统一后台视觉。
5. 本地演示入口复用实际客户端组件，通过 Context 注入内存请求实现。真实 /admin 和 /api/admin 保持原有鉴权。预览入口仅 development 且显式启用时开放，生产返回 404；演示写入只在内存中生效，未实现的操作返回明确错误。
6. 运行 ESLint、TypeScript、国际化检查及相关非 UI 测试；Node.js + Playwright 验证本地预览导航、角色可见性、筛选、窄屏溢出与错误。手动视觉验收由用户完成。

## 设计约定
- 氛围：中性、紧凑的运营工作台，RIIC 品牌与现有中文术语优先。
- 色彩：沿用现有 background/card/foreground/muted/border 语义变量；深色主按钮、浅灰侧栏，状态颜色只表示业务状态。
- 字体：保留现有中文系统字体，正文 14px，辅助信息 12px，页标题 24px/600，数据等宽对齐。
- 组件：Tailwind；复用现有 Base UI 按钮、侧栏、抽屉、弹窗。圆角采用 6/8/10/14px。不覆盖前台组件样式。
- 布局：桌面 240px 侧栏、56px 工具栏，内容最大 1440px，24–32px 页面边距；表格按信息类别组织列。
- 层次：浅灰侧栏、白色内容、细分隔线；无装饰背景。
- 约束：不迁移 Vite/TanStack Router/Clerk，不改变接口语义和服务端权限，不将演示数据当作真实运行数据。
- 响应式：768px 以下使用抽屉；表格容器内横向滚动，页头和筛选换行；保留键盘焦点与 reduced-motion。
- 后续指引：新后台页面沿用 adminPageClass 和 AdminPageHeader；服务端负责权限，客户端负责展示；预览请求经 AdminDataProvider 注入。
