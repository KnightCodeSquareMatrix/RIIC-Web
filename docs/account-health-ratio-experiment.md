# Box 钱书需求比方法实验

运行：

```powershell
node --experimental-strip-types scripts/evaluate-training-ratio.mts --boxes ../3004/boxes --sample 240 --seed 20260924 --rounds 5
```

脚本只读 Box，固定随机种子，不输出账号名、文件名或干员名单。823 份输入中有 816 种不同的四至六星持有练度画像；以 240 份为样本，192 份建立缺样本时的星级先验，48 份做账号内留出检验。每轮隐藏测试账号约四分之一的精二 40 级及以上干员等级，再用其余精二干员预测隐藏群体的总龙门币/总经验比。5 轮得到 235 次有效对照。隐藏群体的星级组成在预测时视为已知，以单独检验等级目标推断；这不是未来培养对象选择的测试。

## 方法与结果

所有方法按四、五、六星分别计算，用项目内 `trainingCost` 矩阵计入升级和精英化费用；最后汇总龙门币与经验再相除。无模组、材料、技能或专精费用。

| 方法 | 星级内代表目标 | 留出绝对误差均值，种子 20260924 / 20260925 | 追加 50% 精二 1 级样本后的预测变化均值，首个种子 |
|---|---|---:|---:|
| 全部精二中位数 | 所有精二等级的中位数 | 0.0236 / 0.0220 | 0.0378 |
| 全部精二众数 | 所有精二等级的最高频等级，同频取低等级 | 0.0267 / 0.0241 | 0.1129 |
| 已继续培养中位数 | 精二 40 级及以上的等级中位数 | 0.0139 / 0.0147 | 0 |
| 已继续培养消耗期望 | 逐人算成本，再分别求平均龙门币和经验 | **0.0063 / 0.0066** | 0 |
| 收缩的消耗期望 | 上法加入 4 人权重的总体星级先验 | 0.0069 / 0.0073 | 0 |

留出误差衡量对账号**已观察到的较高练度分布**的预测，不衡量玩家未来意图。已继续培养的目标筛选门槛设为精二 20/40/50 级时，消耗期望法在首个种子的误差分别为 0.0082/0.0063/0.0075。留出群体本身按精二 40 级及以上定义，因此 40 级表现最好并不能证明它是真实的培养终点门槛。样本中精二 1 级占全部精二的比例中位约 9.3%，90 分位约 24.3%。众数尤其容易因精二 1 级数量变化而突然切换目标等级。

## 需求含义与缺项

首个种子中，已继续培养消耗期望法给出的账号级**从零养到典型练度**钱书比中位为 1.211，10–90 分位为 1.173–1.254。这是每账号个性化结果的分布，不应把总体中位数 1.211 当成所有账号的答案。

另一种明确假设是“把当前精二 1 级干员升级到该账号已继续培养干员的典型练度”。有精二 1 级干员的 176 份样本，其**增量**钱书比中位为 0.828，10–90 分位为 0.758–0.905。精英化龙门币已经付出，后续升级的需求比例自然低于从零培养。Box 无法判断这些精二 1 级干员是待升级还是只为基建技能精二，因此不能把这一情景直接当作实际计划。

所有 823 份 Box 均无模组详情。情景估算：假设未来练的六星中有一半各开一件三级模组，首个样本的钱书比增量中位约 **0.142**，10–90 分位约 0.098–0.192。它不是从 Box 推断出的模组概率，只用于展示遗漏模组可能比方法间差异更重要。

## 推荐

自动基线采用**分星级的已继续培养消耗期望**：只从精二 40 级及以上干员学习该账号的等级终点，以目标干员的星级组成加权合计钱书消耗；每星级样本少时用收缩估计并降低置信度。另输出精二 1 级比例和“如果升级现有精二 1 级”的增量比作为独立情景，不把它并入默认目标。模组信息缺失时标明“未计模组”，可提供显式情景区间；不要用无依据的固定模组概率伪装成个人预测。

这批 Box 可以选出较稳定的**练级模式**，仍无法验证未来培养频率、目标干员选择、精二 1 级意图和模组计划。要验证最终产品建议，需要有玩家自述目标或一段时间后的干员池变化作为标签。`src/account-health-input.ts` 已采用逐人累加消耗的需求比，模组数据可用时按每件实际等级计费；实验脚本仍用于复现无模组 Box 的方法比较。
