# 助理与付费计划开放策略

两个功能默认仅管理员可用。缺失或拼错配置值不会公开功能。

| 服务端环境变量 | admin（默认） | public | disabled |
| --- | --- | --- | --- |
| AGENT_ACCESS_MODE | 仅管理员 | 对外开放，调用仍须登录 | 关闭助理 |
| BILLING_ACCESS_MODE | 仅管理员 | 对外开放，调用仍须登录 | 关闭付费计划 |

管理员沿用用户数据库的 admin 角色及 BETTER_AUTH_ADMIN_USER_IDS 引导管理员名单；reviewer 不算管理员。每次受保护 API 请求重新读取数据库角色，封禁或已删除账号不能使用。不会信任客户端角色、localStorage 或缓存 Session 内的角色。

默认模式下，普通用户与游客看不到智能助理分类、历史记录和付费计划，也不会预取相关路由。直接访问 /agent、/billing 和 /plan/[id] 不渲染受保护页面；API 对游客返回 401、非管理员返回 403，关闭时返回 404。页面渲染和 API 使用同一策略。权限查询失败时隐藏入口；重新聚焦窗口会刷新权限，退出/切换账号会撤下界面并停止本地会话。已开始的服务端请求不属于即时撤销机制，但后续请求会重新鉴权。

受保护 API 包括助理状态、对话和排班产物，以及积分余额、订单创建/查询、兑换码生成/兑换、模拟支付。模拟支付额外要求管理员和原有 BILLING_PROTOTYPE_MODE 环境限制，公开付费计划不会开放免费到账接口。

## 爱发电回调

支付平台回调不使用浏览器登录态，否则已支付订单无法到账。它必须通过服务器向爱发电主动查询确认交易号、成功状态、订单关联和金额，不能相信浏览器提交的付款字段。配置 AFDIAN_API_TOKEN 与 AFDIAN_USER_ID；若配置 AFDIAN_WEBHOOK_SECRET，同时检查该密钥。回调可为开放策略变更前已支付的真实订单结算，不能用于普通用户发起新订单或使用付费页面。

## 后续全面上线

1. 验证生产模型接口、独立知识库/人格卡路径、积分与支付配置及真实支付回调。
2. 先保持两个变量为 admin，分别以管理员和普通账号验收。
3. 将待开放功能的服务端变量改为 public 并重启服务。无需改代码或重新打包前端，页面、导航、API 同步采用策略；现有账号积分和五条本地对话历史不迁移、不清除。
4. 回退为 admin 可收回普通用户访问；disabled 则关闭该功能。已有付款仍可经验证后入账。

常规 Playwright 交互用例使用显式 public 测试配置；production-profile 保持 admin，覆盖真实服务端页面/API 拒绝访问。权限策略与接口无副作用拦截另有非 UI 回归测试。
